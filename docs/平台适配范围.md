# 支持的投稿平台

| 平台 | 每个期刊的入口格式 | 登录方式 |
| --- | --- | --- |
| ScholarOne | `https://mc.manuscriptcentral.com/<journal>` 或 `mc03` 等编号域名 | 期刊账号密码 |
| IEEE 投稿门户 | `https://ieee.submission.researchexchange.com/submission/dashboard` | IEEE 账号密码 |
| Editorial Manager | `https://www.editorialmanager.com/<journal>` | 期刊账号密码 |
| Elsevier 的 Editorial Manager | `https://www.editorialmanager.com/<journal>` | Elsevier 账号密码 |
| Wiley Research Exchange | `https://authors.wiley.com/journal/<code>` 或 `https://submission.wiley.com/journal/<code>` | Wiley 账号密码 |
| MDPI SuSy | `https://susy.mdpi.com/user/manuscripts/status` | MDPI 账号密码 |

Elsevier 的多数期刊投稿使用各期刊自己的 Editorial Manager 入口，见 [Elsevier 官方帮助](https://service.elsevier.com/app/answers/detail/a_id/8000/supporthub/assessment-builder/)。Wiley 的 Research Exchange 按期刊入口进入，账号登录后查看投稿列表，见 [Wiley 官方说明](https://authors.wiley.com/help/submitting-your-manuscript.html)。

IEEE 投稿门户使用 IEEE 账号登录。入口会跳转到 IEEE 登录页；已有账号使用“Sign In”，无需新建账号。见 [IEEE 投稿门户官方说明](https://newauthors.ieeeauthorcenter.ieee.org/author-tools/ieee-publishing-portal/)。

MDPI 投稿使用 SuSy。首次添加后可先使用“打开验证窗口”完成登录；自动读取仅识别稿件编号、期刊、标题和状态等作者稿件表格字段。MDPI 若变更页面结构，应用会提示需要适配，并保留已有记录。

PaperCept 与 OJS 3.4 不再接入自动读取。旧版中添加的这类记录会保留在本地，建议在确认不需要后自行删除。网站若更改登录或稿件列表页面，自动读取可能需要更新适配；遇到验证码请使用“打开验证窗口”。
