# 使用指南

## 开始使用

先在电脑上安装 Google Chrome。PaperTrail 的所有投稿入口都通过独立的 Chrome 账号目录读取，不使用 Chrome 的日常个人资料。ScholarOne 自动读取时会显示 Chrome 窗口；网站若要求安全验证，可在窗口中完成。

1. 在“期刊账号”添加期刊名称、该期刊的投稿入口、登录账号和密码。不同期刊即使使用同一平台，也应填写各自的入口网址。
2. 在“稿件”中添加要跟踪的稿件号，选择所属期刊账号；可填写当前状态。
3. 点击“立即刷新”读取网站状态。网站要求验证码或其他人工步骤时，在账号卡片中点击“打开验证窗口”。

主窗口以竖向卡片显示期刊名字、状态、稿件号和最近一次**本地**状态变化时间。点击稿件号可查看变化次数与本地日志。首次保存或首次读取只建立起点，不追溯投稿网站过去的变化。

支持的入口格式与登录方式见 [平台适配范围](平台适配范围.md)。仅同步主动添加的稿件，不会把账号里的全部稿件导入。

## 菜单栏快览

点击屏幕上方的 PaperTrail图标，可直接查看全部已跟踪稿件的期刊、状态和稿件号。右上角圆形箭头刷新状态；底部分隔线下可打开主页面或退出应用。稿件较多时列表可滚动。

关闭主窗口后，Mac Dock 图标隐藏，定时刷新继续运行；再次打开主页面时 Dock 图标恢复。窗口页面和快览页面均按需创建、关闭后释放。每个账号读取完成后立即关闭投稿浏览器，登录会话仍保留。

## 刷新时间

启用自动刷新后，可在“设置与数据”中增删每天的刷新时间点并选择时区。初始设置为 08:00 至 23:00 每小时一次，加次日 00:00。关闭窗口但保持后台运行时，定时任务继续执行。电脑休眠和关机期间无法读取；恢复后会合并错过的刷新时段。遇到需要人工验证的账号，定时任务会暂停该账号的重复尝试；完成验证后恢复。

网站不可连接或登录失败时，原有状态和变化日志保留。可在“期刊账号”查看错误并重新刷新。
从 1.2 升级到 1.2.1 后，旧 Firefox 会话 Cookie 会尝试导入 Chrome；网站仍可能要求重新登录。旧浏览器组件不会被新版继续使用。

## 数据与备份

“设置与数据”中可以导出或恢复 `.papertrail` 备份，打开本地数据目录，以及检查并安装 GitHub Release 最新版本。安装前会校验下载文件的 SHA-256。密码和浏览器会话不会包含在备份中；恢复后需重新保存账号密码。

- Mac 数据目录：`~/Library/Application Support/PaperTrail/`
- Windows 数据目录：`%LOCALAPPDATA%\PaperTrail\`

删除稿件、账号或期刊只影响本机记录，不会修改投稿网站上的稿件。
