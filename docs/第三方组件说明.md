# 第三方组件

PaperTrail 的 Mac 和 Windows 安装包含 Electron（MIT，内置 Node.js）、CPython（PSF）、Playwright（Apache-2.0）和 tzdata。读取投稿网站使用用户已安装的 Google Chrome；安装包不包含或下载浏览器。

各内置组件的 LICENSE、LICENSE.txt、COPYING 或其他原始许可文件保留在对应运行目录中。Google Chrome 由用户自行安装，其许可由 Google 提供。

Mac Python 运行时来自 Astral python-build-standalone 的官方构建；Windows Python 来自 python.org 官方嵌入式发行包。Playwright 版本见 runtime/runtime-manifest.json；Chrome 版本由系统安装决定。

本产品未获得期刊投稿平台的官方授权或背书；支持范围见平台说明。
